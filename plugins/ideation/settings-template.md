# Ideation Pipeline Settings

Copy this file to `.claude/ideation.local.md` in your project root.

| Field | Default | Description |
|-------|---------|-------------|
| `default_run_prefix` | `ideation-run` | Prefix for auto-numbered run folders (e.g. `ideation-run-01`) |
| `output_root` | `.` | Directory where run folders are created. Relative to workspace root. |
