# Employment Data Template

Copy this file to `finance/data/employment.md` in your Obsidian vault and fill in your details.

---

## Current Employment

| Field | Value |
|-------|-------|
| Employer | |
| Position / Title | |

### Income

| Field | Value | Notes |
|-------|-------|-------|
| Gross annual salary (Bruttojahresgehalt) | EUR | Including regular bonuses if contractual |
| Net monthly salary (Nettogehalt) | EUR | After all deductions |
| Steuerklasse (tax class) | I / II / III / IV / V | |
| Kirchensteuer (church tax) | Yes / No | If yes, which rate (8% or 9%) |
| Annual bonus | EUR | Variable / guaranteed |
| Other variable compensation | EUR | e.g., stock options, profit sharing |

### Social Insurance

| Field | Value |
|-------|-------|
| Gesetzliche Krankenversicherung (GKV) or Private (PKV) | GKV / PKV |
| Health insurance provider | e.g., TK, AOK, Barmer |
| Additional health insurance contribution rate (Zusatzbeitrag) | % |

| Employee contribution (Entgeltumwandlung) | EUR/month |

| Vesting period | years or immediately vested |

| Field | Value |
|-------|-------|
| Employer VL contribution | EUR/month (max EUR 40) |
