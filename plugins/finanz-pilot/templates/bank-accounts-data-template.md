# Bank Accounts Data Template

Copy this file to `finance/data/bank-accounts.md` in your Obsidian vault and fill in your details. Add one section per account.

---

## Account 1

| Field | Value |
|-------|-------|
| Bank | e.g., DKB, ING, N26, Commerzbank |
| Account type | Girokonto (current) / Tagesgeld (savings) / Festgeld (fixed deposit) / Depot (brokerage) |
| Balance | EUR |
| As-of date | YYYY-MM-DD |
| Interest rate | % (for Tagesgeld/Festgeld) |
| Maturity date | YYYY-MM-DD (for Festgeld only) |
| Earmark | emergency fund / down payment savings / general savings / investment |
| Freistellungsauftrag filed | EUR amount allocated to this bank |

- Flag any accounts with pending Festgeld maturity in the next 12 months
