# dev-workflow

Developer workflow skills for day-to-day engineering work with Claude Code.

## Installation

```
/plugin install dev-workflow@marketplace-claude
```

## Skills

- `babysit-pr` - Monitor a PR until it is ready to merge (CI, review comments, fixes)
- `spike` - Run throwaway prototypes to settle which approach to take
- `metaprompt` - Turn a task description into a reusable prompt template
- `session-cleanup` - Analyze and close stale Claude Code background sessions
- `planning-with-files` - Persistent markdown files for planning and progress tracking
- `project-scaffold` - Scaffold new projects (frontend, CLI, API, monorepo)
- `project-bootstrapping` - Add tooling, docs and workflow automation to new or existing projects
- `skill-creator` - Create, edit and package skills

## Commands

- `/dev-workflow:execute-plan` - Execute a written plan

## Agents

- `senior-dev-advisor` - Technical leadership advisor for architecture and implementation decisions

## Output styles

- `technical-lead`
