# kjgarza-product

Product management toolkit with document processing, integrations, and research capabilities.

## Installation

```
/plugin install kjgarza-product@marketplace-claude
```

## Features

### Document Processing

- **PDF**: Read, create, and manipulate PDF files
- **DOCX**: Word document processing
- **XLSX**: Excel spreadsheet operations
- **PPTX**: PowerPoint generation

### Integrations

- **Google Drive**: Search and access documents
- **Coda**: Document search and retrieval
- **Dimensions API**: Academic research database

### Product Management

- PRD creation
- User story generation
- Feature analysis
- Backlog prioritization

## Commands

| Command | Description |
|---------|-------------|
| `/create-prd` | Create a Product Requirements Document |
| `/create-user-stories` | Generate user stories from requirements |
| `/analyze-intel` | Analyze competitive intelligence |
| `/analyze-feature-request` | Evaluate feature requests |
| `/prioritize-backlog` | Help prioritize product backlog |
| `/plan-usability-test` | Plan usability testing sessions |
| `/facilitate-design-critique` | Guide design critique sessions |
| `/search-user-research` | Search user research data |

## Agents

### product-manager

Expert product strategy agent for roadmapping, prioritization, and stakeholder communication.

### scholarly-comms-researcher

Research methodology expert for academic and market research.

### senior-dev-advisor

Technical leadership advisor for architecture and implementation decisions.
