# file-tools

Local file utilities: organize folders, find duplicates, and process images.

## Installation

```
/plugin install file-tools@marketplace-claude
```

## Skills

- `file-organizer` - Analyze directories, find duplicates, suggest structure, automate cleanup
- `image-processing` - ImageMagick conversion, resizing, cropping, batch processing, watermarks

Requires ImageMagick for `image-processing` (`brew install imagemagick`).
